Firebase Config

ไปที่ Firebase Console → Project settings → General → Your apps → SDK setup and configuration แล้วคัดลอกก้อน config (จะเป็น const firebaseConfig = {...} หรือ JSON ก็ได้) มาวางที่นี่ทั้งก้อน ระบบจะดึงเฉพาะส่วน object ออกมาให้เอง

⚠️ ต้องตั้ง Firestore Security Rules ก่อนใช้งานจริง 
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}

วาง rules นี้ที่ Firebase Console → Firestore Database → Rules แล้วกด Publish (rules นี้เปิดให้ทุกคนอ่าน/เขียนได้ — เหมาะกับการใช้งานส่วนตัว/ทดสอบเท่านั้น ถ้าต้องการความปลอดภัยเพิ่ม ควรเพิ่ม Firebase Authentication ภายหลัง)
